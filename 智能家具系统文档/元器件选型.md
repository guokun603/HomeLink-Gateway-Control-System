
# 智能家居系统器件选型

## 1. 控制芯片

| 控制芯片               | 数量/用途     | 主要功能                                     |
| ------------------ | --------- | ---------------------------------------- |
| **RK3588**         | 1，系统主控    | Linux系统、智能家居管理、Web控制、设备管理、AI处理、数据存储、网络通信 |
| **ESP32-S3-N16R8** | 1，AI语音助手  | 小智AI语音终端、WiFi通信、语音采集与播放                  |
| **STM32F407CGT6**  | 1，智能监控    | OV7670图像采集、2自由度云台控制、监控节点控制               |
| **STM32F103C8T6**  | 1，智能门锁    | NFC、指纹、密码验证、门锁电机、蜂鸣器等控制                  |
| **ESP8266**        | 多个，设备通信节点 | WiFi通信、智能门锁/监控/家居设备的数据传输                 |

# 2. 智能门锁

**主控：STM32F103C8T6**

|器件|作用|与STM32连接|
|---|---|---|
|**RFID-RC522**|RFID/M1卡读卡|SPI|
|**M1 IC蓝卡**|用户身份识别卡|RC522读取|
|**M1 IC白卡**|用户身份识别卡|RC522读取|
|**矩阵按键**|密码输入、功能操作|GPIO|
|**海陵科 ZW101 指纹识别模块**|指纹录入、指纹识别|UART|
|**ESP8266**|WiFi远程通信|UART|
|**电机**|门锁机械机构驱动|GPIO/PWM + 电机驱动|
|**蜂鸣器**|开锁提示、错误报警、状态提示|GPIO/PWM|

### 门锁功能

```text
              STM32F103C8T6
                     │
       ┌─────────────┼─────────────┐
       │             │             │
     RC522         ZW101        矩阵按键
       │             │             │
      RFID          指纹           密码
       │             │             │
       └─────────────┼─────────────┘
                     │
                  身份验证
                     │
              ┌──────┴──────┐
              │             │
            开锁           拒绝
              │             │
             电机          蜂鸣器
              │
             门锁
```

同时：

```text
STM32F103
    │ UART
    ▼
ESP8266
    │ WiFi
    ▼
RK3588
```

用于实现：

- 远程查看门锁状态
    
- 远程开锁
    
- 开锁记录上传
    
- 用户管理
    
- RFID卡管理
    
- 指纹管理
    
- 密码管理

# 3. 智能监控

**主控：STM32F407CGT6**

|器件|作用|与STM32连接|
|---|---|---|
|**OV7670（无FIFO）**|摄像头图像采集|DCMI/并口 + SCCB|
|**舵机 ×2**|水平、垂直两个方向运动|PWM|
|**ESP8266**|WiFi通信|UART|

### 监控结构

```text
                 STM32F407CGT6
                       │
             ┌─────────┴─────────┐
             │                   │
          OV7670               2个舵机
         摄像头                  │
             │             ┌─────┴─────┐
             │             │           │
             │           水平        垂直
             │            PAN         TILT
             │
             └────────┐
                      │
                  图像采集
                      │
                  ESP8266
                      │
                     WiFi
                      │
                   RK3588
```

可以实现：

- 实时监控
    
- 云台水平控制
    
- 云台垂直控制
    
- 云台自动巡视
    
- 远程查看
    
- 后续接入 RK3588 AI视觉识别

# 4. 智能家居

这里建议把 **ESP8266作为各类智能家居设备的WiFi节点**。

|器件|作用|控制方式|
|---|---|---|
|**ESP8266**|智能家居WiFi节点|WiFi|
|**继电器模块**|控制灯、电器等|GPIO|
|**DS18B20**|温度检测|单总线|
|**DHT11**|温湿度检测|单总线|
|**38kHz红外接收模块**|接收家电遥控器红外信号|GPIO|
|**38kHz红外发送模块**|模拟遥控器控制家电|GPIO/PWM|
|**红外遥控器**|获取/测试红外控制码|红外|
|**LED灯**|智能照明|继电器/GPIO|
|**HC-SR501**|人体感应|GPIO|
|**电机**|风扇/窗帘等执行机构|电机驱动|

### 智能家居节点

```text
                 ESP8266
                    │
       ┌────────────┼────────────┐
       │            │            │
    DS18B20       DHT11       HC-SR501
    温度           温湿度       人体检测
       │            │            │
       └────────────┼────────────┘
                    │
              ┌─────┴─────┐
              │           │
           继电器       红外模块
              │           │
          ┌───┴───┐    家用电器
          │       │
        LED灯    其他设备
```

可以实现：

- 自动开灯
    
- 人来灯亮
    
- 人走灯灭
    
- 温度检测
    
- 湿度检测
    
- 风扇控制
    
- 红外遥控家电
    
- 远程控制家庭设备
    
- 自动化场景

# 5. AI语音助手

**主控：ESP32-S3-N16R8**

|器件|作用|与ESP32-S3连接|
|---|---|---|
|**ESP32-S3-N16R8**|小智AI语音终端|主控|
|**INMP441**|数字麦克风|I2S|
|**MAX98357**|I2S音频功放|I2S|
|**扬声器**|AI语音播放|MAX98357输出|

### 结构

```text
                  ESP32-S3-N16R8
                   小智AI终端
                       │
             ┌─────────┴─────────┐
             │                   │
          INMP441             MAX98357
          麦克风               音频功放
             │                   │
           语音输入              │
                                 ▼
                              扬声器
```

ESP32-S3通过WiFi连接网络/小智AI服务。

然后与你的RK3588智能家居系统进行联动：

```text
你：
“打开客厅灯”
       ↓
ESP32-S3
       ↓
小智AI
       ↓
WiFi
       ↓
RK3588
       ↓
ESP8266
       ↓
继电器
       ↓
客厅灯
```

| 芯片            | 定位        |
